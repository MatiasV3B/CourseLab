# Contributing to CourseLab

Thank you for your interest in contributing to CourseLab! Contributions of all kinds are welcome, including bug reports, feature suggestions, documentation improvements, and code contributions.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your changes:

   ```bash
   git checkout -b feature/your-feature-name
   ```

3. Make your changes and test them locally.
4. Commit your changes with a clear and descriptive message.
5. Push your branch to your fork.
6. Open a pull request explaining what you changed and why.

## Reporting Bugs

Before opening a bug report, please check whether the issue has already been reported.

When reporting a bug, include:

- A clear and descriptive title
- Steps to reproduce the issue
- Expected behavior
- Actual behavior
- Screenshots or error messages, if available
- Browser, operating system, and device information

## Suggesting Features

Feature suggestions are welcome. Please open an issue and explain:

- The problem your suggestion would solve
- How the feature should work
- Why it would be useful for CourseLab users

## Code Style

- Keep code clean, readable, and well organized.
- Use meaningful variable and function names.
- Follow the existing project structure and formatting.
- Test your changes before submitting a pull request.
- Avoid including secrets, API keys, passwords, or personal data.

## Pull Requests

Before submitting a pull request, make sure that:

- Your changes are focused on one feature or fix.
- The application builds and runs without errors.
- You have updated documentation when necessary.
- Your pull request description clearly explains the purpose of the changes.

Thank you for helping improve CourseLab!
