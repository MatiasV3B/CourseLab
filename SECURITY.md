# Security Policy

## Supported Versions

Only the latest version available on the `main` branch is currently supported with security updates.

| Version | Supported |
| ------- | --------- |
| `main`  | ✅ |
| Previous versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in CourseLab, please do **not** open a public issue or disclose the vulnerability publicly.

Instead, report it privately to the repository maintainer through GitHub. Please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested fix, if available

Please do not include passwords, API keys, access tokens, personal information, or other sensitive data in your report.

## Response Process

After receiving a report, the maintainer will review it and respond as soon as possible. If the issue is confirmed, a fix will be developed and released before public disclosure whenever possible.

Thank you for helping keep CourseLab and its users safe.
